# Almare – Sistema de Reservas de Hospedagem

Aplicativo desenvolvido em .NET MAUI como parte da atividade da Agenda 13 da disciplina de Desenvolvimento de Sistemas II, do curso Técnico em Desenvolvimento de Sistemas da ETEC.

## Sobre o projeto

O **Almare Resort** é um aplicativo demonstrativo de reservas de hospedagem, desenvolvido com uma identidade visual inspirada em resorts e na natureza.

O projeto foi personalizado com uma paleta de cores neutras, azul elegante e tons de areia dourada, buscando transmitir conforto, tranquilidade e sofisticação.

## Funcionalidades

- Seleção da quantidade de adultos e crianças.
- Escolha de acomodação conforme a capacidade de hóspedes.
- Seleção das datas de check-in e check-out.
- Cálculo do valor total da hospedagem conforme a acomodação e o período.
- Exibição do resumo da reserva.
- Confirmação da reserva e apresentação dos dados em uma tela final.
- Tela Sobre com informações do desenvolvedor e do projeto.

## Tecnologias utilizadas

- C#
- XAML
- .NET MAUI
- .NET 8

## Observação

Este aplicativo possui finalidade acadêmica e demonstrativa. As reservas são simuladas, sem integração com banco de dados ou sistema de pagamentos.
